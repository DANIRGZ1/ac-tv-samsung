# Seguridad

AC TV es un proyecto experimental para Samsung Tizen. Esta política cubre el código de este repositorio y el instalador incluido.

## Comunicar una vulnerabilidad

No publiques vulnerabilidades sin corregir, datos de explotación ni información privada en Issues o Discussions. Si GitHub muestra **Report a vulnerability** en la pestaña **Security** de este repositorio, úsalo para enviar un aviso privado. La disponibilidad de esa función depende de la configuración del repositorio.

Si la opción no aparece, puedes abrir un issue sin detalles técnicos ni información sensible para pedir un medio privado de contacto.

Incluye una descripción breve, pasos para reproducir, impacto observado y la versión o commit afectado. Omite certificados, claves, contraseñas, números de serie, IP públicas y listas o enlaces Ace Stream personales. Coordina la publicación de detalles con quien mantenga el proyecto.

## Alcance

Se consideran dentro del alcance los fallos de seguridad reproducibles en la aplicación, su procesamiento local de enlaces/listas y los scripts de instalación de este repositorio. No envíes contenido de terceros ni informes sobre disponibilidad o autorización de emisiones.
