# Contribuir

Mantén la compatibilidad con Chromium 85 y Tizen 6.5. Evita dependencias del PC para reproducción. Ejecuta npm test; para cambios visuales ejecuta npm run test:ui con Chrome. No subas listas, enlaces personales, certificados o capturas con información privada. Describe los modelos de TV comprobados y no presentes pruebas de escritorio como comprobaciones físicas.

Para cambios en la instalación, ejecuta `npm run test:installer`. Usa la [guía de compatibilidad](docs/COMPATIBILITY.md) para reportar resultados en un modelo real, tanto si funcionó como si falló.
